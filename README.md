# Assembly-game-test-1

Windows 10 kompatibilis, natív `.exe` játék (WinForms), alap mozgással.

## Vezérlés
- `W A S D`: mozgás
- `Space`: ugrás
- `Shift`: futás
- `Ctrl`: guggolás

## Build
Futtasd a projekt gyökerében:

```bat
build.bat
```

Kimenet:
- `AssemblyGame.exe`

## Futtatás
- dupla katt az `AssemblyGame.exe` fájlon

## Megjegyzés
- A korábbi `game.asm` MARS-os kísérlet volt (emulátor).
- A futtatható Windows 10-es változat forrása: `src/Program.cs`.
